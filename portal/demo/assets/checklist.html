On the platform

Tag the clusters to offer Each one carries a cluster: tag; untagged clusters never appear
Tag the NSX VLAN segments One per zone — MES, FDC, OA; a zone without one cannot be requested
Define the sizes Flavor mappings set the vCPU and memory behind each name
Define the operating systems Image mappings point each name at a template
Give each segment an IP range The platform allocates from it; addresses must be free

On the estate, and to agree

VMware Tools in every template Static IP is written in through guest customization
Confirm the vCenter attribute names Prefer the fields you already use rather than creating new ones
A dedicated service account Not an administrator account
Agree the ticket number format So the form can validate it before anything is built
Agree the list of details to record Six today; adding one later costs a line of configuration
Nothing here needs custom development. Each item is a setting, and once it is in place the portal picks it up on its own — the dropdowns are built from whatever is configured at the time.
